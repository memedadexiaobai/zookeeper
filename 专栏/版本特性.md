ZooKeeper 3.7（首个稳定版为 3.7.0，2022-05 发布）以**安全增强、运维与开发体验升级**为核心，同时补齐了配额管理、测试框架等重要能力；后续 3.7.1/3.7.2 以 Bug 修复与 CVE 加固为主。以下是核心特性与关键变更，按生产视角分类整理。

---

### 核心新特性（生产级）
| 类别 | 关键特性 | 价值与说明 |
| :--- | :--- | :--- |
| 🔐 安全强化 | 多 SASL 超级用户 | 支持配置多个 SASL superUser，适配多团队运维与分级管控。 |
| | 认证方案强制化 | 可指定必须使用的认证方案（如 SASL/SSL），拒绝弱认证。 |
| | 集群 SASL+SSL 与主机名规范化 | 支持 Quorum 间 SASL（Kerberos）+SSL 双重认证；可选主机名规范化，避免解析不一致导致的认证失败。 |
| | 多客户端 SASL 支持 | C、Perl 客户端新增 SASL 认证；Python 客户端支持 SSL。 |
| | BCFKS 密钥库支持 | 兼容 BCFKS 格式，满足更高安全合规要求。 |
| 🛠️ 运维与诊断 | whoami API/CLI | 快速查询当前会话的认证身份，定位权限问题。 |
| | 配额强制执行 | 对节点数、数据大小等配额从“告警”升级为“强制阻止”，防止集群滥用。 |
| | SnapshotComparer | 快照对比工具，辅助定位数据一致性与快照损坏问题。 |
| | zkCli 连接等待选项 | 非交互式脚本可等待连接就绪后再执行命令，提升自动化稳定性。 |
| 🧩 开发与测试 | 嵌入式服务器官方 API | 提供 ZooKeeperServerEmbedded，简化 Java 集成测试与服务启动。 |
| | 确定性测试框架 | 支持运行时行为注入，复现时序相关问题，提升测试有效性。 |
| 📉 可观测性 | 观察者同步时间指标 | 新增 Observer 同步耗时指标，优化读写分离集群的监控与调优。 |

---

### 重要变更与弃用
1. **CLI 命令弃用**：移除 `ls2`、`rmr`（建议用 `ls -R`、`deleteall` 替代）。
2. **依赖与兼容性**：3.7.1 升级 Netty 至 4.1.x，修复多个 CVE；支持 JDK 17 构建与运行（3.7.1+）。
3. **安全修复**：3.7.1 包含多项 CVE 修复，是生产环境的推荐基线版本。

---

### 常见误区澄清
- **持久 Watcher**：该特性为 **3.8.0** 新增，3.7 仍为一次性 Watcher，请勿混淆。
- **动态配置**：3.7 延续 3.5+ 的动态重新配置能力，但未引入“更灵活的动态配置”新特性，相关优化属于后续版本。

---

### 版本选择建议
- 生产环境优先使用 **3.7.2**（最新稳定版），兼顾功能与安全性。
- 若需 JDK 17 支持或最新 CVE 修复，至少升级至 **3.7.1**。
