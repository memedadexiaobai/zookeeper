你想梳理的 `[ ]` 是 Shell 中 `test` 命令（`[]` 是其简写）的**字符串判断参数**用法，`[]` 内部支持字符串、数字、文件三大类判断参数，是 Shell 脚本中条件判断的核心语法。下面我按类别整理所有常用参数，并结合示例说明用法，新手也能快速掌握。

### 先明确核心前提
`[ ... ]` 等价于 `test ...`，是 Shell 内置的条件判断命令，**参数必须和括号、变量之间保留空格**（比如 `[ -n "$VAR" ]` 不能写成 `[-n"$VAR"]`），否则会报语法错误。

## 一、字符串判断类（最常用，对应你的示例）
用于判断字符串是否为空、是否相等，是处理变量（比如配置项、脚本参数）的核心场景。

| 参数       | 含义                                  | 示例（假设 `VAR1="abc"`，`VAR2=""`） | 结果  |
|------------|---------------------------------------|--------------------------------------|-------|
| `-n "$str"` | 判断字符串 `str` **非空**（长度>0）| `[ -n "$VAR1" ]`                     | 真（0） |
| `-z "$str"` | 判断字符串 `str` **为空**（长度=0）| `[ -z "$VAR2" ]`                     | 真（0） |
| `"$str1" = "$str2"` | 判断两个字符串**相等**（=`==` 是 Bash 扩展，等价） | `[ "$VAR1" = "abc" ]`               | 真（0） |
| `"$str1" != "$str2"` | 判断两个字符串**不相等**              | `[ "$VAR1" != "def" ]`               | 真（0） |

#### 关键示例（对应你的场景）
```bash
# 你的示例：判断 ZOO_DATADIR_AUTOCREATE_DISABLE 是否非空（即是否配置了该变量）
if [ -n "$ZOO_DATADIR_AUTOCREATE_DISABLE" ]; then
    echo "禁用自动创建 dataDir 目录" >&2
    # 执行禁用逻辑
else
    echo "自动创建 dataDir 目录"
    # 执行创建逻辑
fi
```

#### 避坑提醒
- 所有字符串变量必须加**双引号**（比如 `[ -n "$VAR" ]` 而非 `[ -n $VAR ]`），否则变量为空时会变成 `[ -n ]`，触发语法错误；
- 等号 `=` 前后必须加空格（`[ "$a" = "$b" ]`），否则会被解析成字符串而非比较运算符。

## 二、数字判断类
用于整数之间的大小比较，**不能用于浮点数**，也不能和字符串判断混用。

| 参数         | 含义               | 示例（假设 `NUM1=10`，`NUM2=20`） | 结果  |
|--------------|--------------------|-----------------------------------|-------|
| `-eq`        | 等于（equal）      | `[ $NUM1 -eq 10 ]`                | 真（0） |
| `-ne`        | 不等于（not equal） | `[ $NUM1 -ne $NUM2 ]`             | 真（0） |
| `-gt`        | 大于（greater than） | `[ $NUM2 -gt $NUM1 ]`             | 真（0） |
| `-lt`        | 小于（less than）  | `[ $NUM1 -lt $NUM2 ]`             | 真（0） |
| `-ge`        | 大于等于           | `[ $NUM1 -ge 10 ]`                | 真（0） |
| `-le`        | 小于等于           | `[ $NUM1 -le 5 ]`                 | 假（1） |

#### 示例：判断脚本参数数量是否合法
```bash
if [ $# -ne 2 ]; then  # $# 是参数总数，判断是否不等于2
    echo "用法：$0 <参数1> <参数2>" >&2
    exit 1
fi
```

## 三、文件/目录判断类
用于判断文件/目录的类型、权限、状态，是脚本中处理文件操作的核心。

| 参数         | 含义                                  | 示例                          | 适用场景                  |
|--------------|---------------------------------------|-------------------------------|---------------------------|
| `-f "$file"` | 判断是否为**普通文件**（非目录/设备） | `[ -f "/etc/passwd" ]`        | 检查配置文件是否存在      |
| `-d "$dir"`  | 判断是否为**目录**                    | `[ -d "$ZOO_DATADIR" ]`       | 检查 dataDir 目录是否存在 |
| `-e "$path"` | 判断路径（文件/目录）**是否存在**     | `[ -e "/tmp/zk.log" ]`        | 通用存在性检查            |
| `-r "$file"` | 判断是否有**读权限**                  | `[ -r "$ZOOCFG" ]`            | 检查能否读取配置文件      |
| `-w "$file"` | 判断是否有**写权限**                  | `[ -w "$ZOO_DATADIR/zk.dat" ]`| 检查能否写入数据文件      |
| `-x "$file"` | 判断是否有**执行权限**                | `[ -x "/bin/grep" ]`          | 检查命令是否可执行        |
| `-s "$file"` | 判断文件**非空**（大小>0）            | `[ -s "$ZK_LOG" ]`            | 检查日志文件是否有内容    |
| `-L "$file"` | 判断是否为**软链接**                  | `[ -L "/etc/zk.cfg" ]`        | 检查配置文件是否是链接    |

#### 示例：检查并创建 ZooKeeper 数据目录
```bash
if [ ! -d "$ZOO_DATADIR" ]; then  # ! 表示“非”，判断目录不存在
    echo "创建 dataDir 目录：$ZOO_DATADIR"
    mkdir -p "$ZOO_DATADIR"  # -p 确保父目录也创建
fi
```

## 四、逻辑组合参数
用于多个条件的组合判断，支持“与、或、非”三种逻辑。

| 逻辑   | 参数/写法       | 含义                 | 示例（判断文件存在且有读权限） |
|--------|-----------------|----------------------|--------------------------------|
| 非     | `!`             | 取反                 | `[ ! -d "$DIR" ]`（目录不存在） |
| 与     | `-a`（或 `&&`） | 两个条件都成立       | `[ -f "$FILE" -a -r "$FILE" ]` |
| 或     | `-o`（或 `||`） | 任意一个条件成立     | `[ -f "$FILE" -o -d "$FILE" ]` |

#### 注意
- `&&`/`||` 是 Bash 扩展，更推荐用在 `[[ ... ]]` 中（比如 `[[ -f "$f" && -r "$f" ]]`）；
- `[]` 中优先用 `-a`/`-o`，但复杂逻辑建议拆分成多个 `[]` 并用 `&&`/`||` 连接（更清晰）：
  ```bash
  # 推荐写法（易读）
  if [ -f "$FILE" ] && [ -r "$FILE" ]; then
      echo "文件存在且可读"
  fi
  ```

## 总结
1. `[]` 是 `test` 命令的简写，核心支持**字符串、数字、文件**三类判断参数；
2. 你的示例 `[ -n "$VAR" ]` 属于**字符串非空判断**，是脚本中检查“是否配置了某个变量”的常用写法；
3. 关键避坑点：变量加双引号、参数和括号间留空格、数字判断用 `-eq/-gt` 而非 `=/>`。
