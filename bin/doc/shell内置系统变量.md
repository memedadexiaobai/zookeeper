你想了解 Shell 中除了 `OSTYPE` 之外的**内置系统变量**，这些变量是 Shell 预定义的、用于获取系统/脚本运行状态的核心变量，在编写跨平台、健壮的脚本（比如你分析的 ZooKeeper 脚本）时非常关键。下面我会按**用途分类**整理常用的内置系统变量，每个变量都配说明和实用示例，新手也能快速理解。

### 一、核心基础：脚本/进程相关变量
这类变量用于获取脚本自身、进程的基本信息，是最常用的一批：

| 变量名 | 含义 | 实用示例 |
|--------|------|----------|
| `$0` | 当前脚本的文件名（包含路径，执行时的写法决定） | 执行 `sh /tmp/test.sh` → `$0` 是 `/tmp/test.sh`；执行 `./test.sh` → `$0` 是 `./test.sh` |
| `$n` | 脚本的第 n 个位置参数（n≥1） | 执行 `sh test.sh a b c` → `$1=a`、`$2=b`、`$3=c`（你之前问的 `$2` 就属于这类） |
| `$#` | 传递给脚本的位置参数总数 | 执行 `sh test.sh a b` → `$#=2` |
| `$*` | 所有位置参数的整体（视为一个字符串） | 执行 `sh test.sh a b` → `"$*"` 是 `"a b"` |
| `$@` | 所有位置参数的列表（每个参数独立） | 执行 `sh test.sh a b` → `"$@"` 是 `"a" "b"`（遍历参数时优先用这个） |
| `$$` | 当前脚本进程的 PID（进程号） | 脚本中 `echo $$` → 输出比如 `12345`（常用于生成唯一临时文件名） |
| `$?` | 上一条命令的退出状态码 | `ls /tmp; echo $?` → 成功则输出 `0`，失败（比如文件不存在）输出非0（如 `2`） |
| `$!` | 后台运行的最后一个进程的 PID | `sleep 10 &; echo $!` → 输出后台 sleep 进程的 PID |
| `$-` | 当前 Shell 的选项标志（比如 `i` 表示交互模式） | 执行 `echo $-` → 输出比如 `himBH`（`h`=历史记录，`i`=交互，`B`= brace 扩展） |

#### 示例：遍历脚本参数（`$@` 的典型用法）
```bash
#!/bin/bash
echo "参数总数：$#"
echo "遍历所有参数："
for arg in "$@"; do
    echo "参数：$arg"
done
```
执行 `sh test.sh apple banana`，输出：
```
参数总数：2
遍历所有参数：
参数：apple
参数：banana
```

### 二、系统环境相关变量
这类变量用于获取操作系统、Shell 环境的核心信息，你之前问的 `OSTYPE` 就属于这类：

| 变量名 | 含义 | 常见值示例 |
|--------|------|------------|
| `OSTYPE` | 当前操作系统类型 | Linux：`linux-gnu`；macOS：`darwin21`；Solaris：`solaris` |
| `PATH` | 命令查找路径（用 `:` 分隔） | `/usr/local/bin:/usr/bin:/bin` |
| `HOME` | 当前用户的主目录 | 普通用户：`/home/user`；root：`/root`；macOS：`/Users/xxx` |
| `PWD` | 当前工作目录（等价于 `pwd` 命令） | `/tmp/workspace` |
| `OLDPWD` | 上一次的工作目录（`cd -` 会用到） | `/home/user` |
| `USER`/`LOGNAME` | 当前登录的用户名 | `root`、`a58` |
| `SHELL` | 当前使用的 Shell 路径 | `/bin/bash`、`/bin/zsh`、`/bin/sh` |
| `LANG` | 系统语言/字符编码 | `zh_CN.UTF-8`、`en_US.UTF-8` |
| `TERM` | 终端类型 | `xterm`、`vt100`、`screen` |
| `UID` | 当前用户的数字 ID | root：`0`；普通用户：`1000`、`501`（macOS） |
| `IFS` | 内部字段分隔符（默认：空格、制表符、换行） | 自定义 `IFS=,` 可按逗号分割字符串 |

#### 示例：判断当前用户是否为 root（`$UID` 用法）
```bash
if [ $UID -ne 0 ]; then
    echo "请用 root 用户执行脚本！" >&2
    exit 1
fi
```

### 三、Bash 特有扩展变量（新版 Bash 支持）
这类是 GNU Bash 扩展的变量，功能更丰富，老版 `sh` 可能不支持：

| 变量名 | 含义 | 示例 |
|--------|------|------|
| `BASH_VERSION` | Bash 版本号 | `5.1.16(1)-release` |
| `BASH_SOURCE` | 当前脚本的绝对路径（比 `$0` 更可靠） | 无论怎么执行脚本，都返回 `/tmp/test.sh` |
| `RANDOM` | 生成 0-32767 的随机数 | `echo $RANDOM` → 输出比如 `12345` |
| `SECONDS` | 脚本启动后经过的秒数 | 脚本开头 `echo $SECONDS`（0），sleep 5 后 `echo $SECONDS`（5） |

### 四、使用注意事项（避坑关键）
1. **变量引用规范**：所有内置变量引用时建议加双引号（比如 `"$0"`、`"$@"`），避免空格/特殊字符导致语法错误；
2. **只读属性**：大部分内置系统变量是“只读”或“自动更新”的（比如 `$PWD` 会随 `cd` 命令自动变），不要手动修改（比如 `$PATH` 可追加，但不建议覆盖）；
3. **兼容性**：`$BASH_VERSION`、`BASH_SOURCE` 等是 Bash 特有，若脚本要兼容 `sh`（比如 Solaris 的 `/bin/sh`），避免使用；
4. **空值处理**：判断变量是否为空时，用你之前学的 `[ "x$VAR" != "x" ]` 或 `[ -n "$VAR" ]`（比如 `[ -n "$PATH" ]` 判断路径是否为空）。

### 总结
1. Shell 内置系统变量分三类：**脚本/进程相关**（`$0`/`$1`/`$?`/`$$`）、**系统环境相关**（`OSTYPE`/`PATH`/`HOME`/`UID`）、**Bash 扩展**（`BASH_VERSION`/`RANDOM`）；
2. 核心常用变量：`$0`（脚本名）、`$n`（参数）、`$#`（参数数）、`$?`（退出码）、`$UID`（用户ID）、`OSTYPE`（系统类型）；
3. 引用变量加双引号、区分 Shell 兼容性，是编写健壮脚本的关键。
